# One Word for the Boss

One word. That is the whole entry.

`main.ts` writes a single word describing the boss to the grader's output
file — no phrase, no caption, no explanation. The word is **Ghost**: the boss
who is never there when you need them, never answers, and somehow still runs
the place. Five letters, one habit every office knows, and it works in a
kitchen, a warehouse, or an office without any explanation.

## Run

```sh
node main.ts
```

The program validates that the entry is exactly one word (1–30 characters,
no whitespace) and writes it deterministically — no clock, no randomness —
to `/output/entry.txt`, falling back to `output/entry.txt` if needed.
